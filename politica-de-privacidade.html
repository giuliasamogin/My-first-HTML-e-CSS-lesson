Política de Privacidade e Proteção de Dados Fictícios

Última atualização: 26 de setembro de 2026 • Versão 2.0-Legal

Aviso Acadêmico / Jurídico: O Fluffify é um projeto fictício de demonstração acadêmica. Não armazenamos seus dados em servidores reais nem comercializamos informações pessoais. Este documento serve para garantir a integridade formal da aplicação.

1. Informações Coletadas

Para fins estritamente lúdicos, de simulação de interface e teste das funcionalidades de cadastro, login e carrinho de compras virtual, o site poderá solicitar temporariamente dados genéricos como nome, e-mail e telefone inseridos pelo usuário.

2. Dados de Cadastro e Simulação

Os dados preenchidos nos formulários de cadastro e autenticação não são enviados a nenhum servidor de banco de dados externo nem compartilhados com terceiros. Todas as interações e validações de sessão ocorrem estritamente dentro do ambiente local do navegador.

3. Uso das Informações

As informações digitadas são utilizadas exclusivamente para personalizar a experiência visual na tela do usuário — tal como exibir o nome cadastrado no cabeçalho ou simular a listagem de itens adicionados ao carrinho de compras.

4. Armazenamento, Cookies e LocalStorage

Utilizamos recursos padrões de desenvolvimento web, tais como o localStorage do navegador, com o único propósito de salvar provisoriamente os itens do carrinho e manter o estado de login simulado enquanto o usuário navega pelas páginas do projeto. Estes registros podem ser eliminados a qualquer instante mediante limpeza de cache ou histórico local.

5. Segurança dos Dados

Ainda que se trate de um projeto estudantil desprovido de um backend real ou infraestrutura corporativa de segurança, recomenda-se veementemente que o usuário abstenha-se de utilizar dados, credenciais ou senhas reais e sensíveis (utilizadas em serviços bancários ou e-mails pessoais) nos campos de preenchimento da plataforma.

6. Compartilhamento de Informações

Em hipótese alguma os dados informados nesta aplicação web serão vendidos, repassados, comercializados ou divulgados a quaisquer entidades externas, físicas ou jurídicas.

7. Direitos do Usuário

O usuário mantém plena liberdade para encerrar sua navegação, fechar a aba do navegador, zerar os dados armazenados localmente ou interromper a interação com o sistema a qualquer momento, sem ônus ou penalidades.

8. Canais de Contato

Eventuais dúvidas relativas ao escopo deste projeto acadêmico e ao tratamento hipotético de dados podem ser encaminhadas diretamente através da nossa página de Fale Conosco.
